Download the `RMT_SPD_Module_V1.0.1.zip` package from trusted GSM hosting repositories. Extract the archive directly to your primary drive (e.g., `C:\RMT_SPD_Module\`) using WinRAR or 7-Zip.

*Verification:* Confirm the extracted folder contains `RMT SPD Module.exe` along with necessary support execution files.


2. **Install Unisoc / SPD Drivers:** Prerequisite Driver Setup.
Download and execute the **Spreadtrum / Unisoc Official USB Driver Pack** on your system to ensure stable port communication. Reboot your PC after completing installation.

*Verification:* Open Windows **Device Manager** (`devmgmt.msc`) and confirm that no driver error flags appear under `Ports (COM & LPT)` when plugging in a Unisoc handset.


3. **Launch the Utility:** Administrator Privileges Required.
Right-click `RMT SPD Module.exe` and select **Run as Administrator**.


4. **Select Action & Connect Device:** Hardware Connection.
Select your required servicing task from the tool interface (such as **Recovery Wipe Data + FRP** or **Erase FRP Only**). Power off the smartphone completely, hold the **Volume Down** or **Volume Up** boot key, and plug in the USB cable connected to your PC.

*Verification:* The log window will display a progress indicator followed by an **OK** or **Success** message once completed.
